
## Артель + Верстак + Реактроник: демонстрация возможностей

Для разработки и запуска требуются:

- NodeJS 20+ ([ссылка](https://nodejs.org/)).
- Visual Studio Code 1.95+ ([ссылка](https://code.visualstudio.com/)).
- Расширение Артель для VS Code 0.6.26035+ ([ссылка](https://marketplace.visualstudio.com/items?itemName=nezaboodka.artel-vscode))

Запуск веб-сервера из командной строки для локального
хостинга приложения:

``` shell
> npm run запуск-сервера
```

При первом запуске сервера автоматически будет
установлен сам компилятор Артель и все нужные пакеты
(в локальную папку "node_modules"), а также выполнена
компиляция/сборка проекта (в папку ".сборка").

После запуска веб-сервера приложение можно открыть в
браузере: http://localhost:1234.

При внесении изменений в исходный код сборку нужно
осуществлять вручную, чтобы веб-сервер подхватил
изменения.

``` shell
> npm run собрать
```

Можно также запустить приложение на отладку прямо из
VS Code с поддержкой точек останова (breakpoints). Для
этого на компьютере должен быть установлен браузер
Chrome.
